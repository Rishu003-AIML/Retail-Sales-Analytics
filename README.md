# 📊 Retail Sales Analytics

## About the Project

I created this project to practice my data analytics skills using a retail sales dataset. The goal was to clean the data, analyze sales and profit trends, and create visualizations that help understand business performance.

This project helped me improve my knowledge of data cleaning, exploratory data analysis (EDA), SQL, and dashboard creation.

---

## Project Goals

- Clean and prepare the sales dataset
- Explore sales and profit trends
- Identify top-performing products and regions
- Create meaningful visualizations
- Build an interactive dashboard for business insights

---

## How to Run

1. Clone this repository

2. Install the required libraries

```bash
pip install -r requirements.txt
```

3. Run the analysis

```bash
python analysis.py
```

The script will:
- Load the retail sales dataset
- Clean and analyze the data
- Generate visualizations
- Display business insights
---

## Key Findings

- The Technology category generated the highest sales.
- The West region performed better than other regions in terms of revenue.
- Consumer customers contributed the largest share of total sales.
- Some products had high sales but low profit, showing opportunities to improve pricing or reduce costs.
